# Activación de Licencia (cliente)

> El flujo v1 (importar ZIP con license.json) fue **eliminado**. El cliente
> activa pegando un token: no hay archivos, ni JSON, ni IDs técnicos.

## Paso a paso (Administración → Licencia)

1. Escribe el **nombre del negocio** (el proveedor lo necesita para la licencia).
2. Pulsa **«Copiar código de solicitud»** — el código `VLREQ2-…` queda en el
   portapapeles (también aparece en un recuadro por si el copiado falla).
3. **Envíalo por WhatsApp** al proveedor (52973387) — el recuadro incluye un
   botón «Abrir WhatsApp».
4. Espera el **token de licencia** (`VLBA2-…`).
5. Pégalo en **«Token de licencia»** y pulsa **«Activar licencia»**.
6. Resultado: **LICENCIA ACTIVA** con cliente, «Vence el DD/MM/YYYY» y
   «Restan X días». La marca de agua de la TV desaparece en segundos.

## Si algo falla (mensajes humanos, sin detalles técnicos)

| Mensaje | Significado / acción |
|---|---|
| «El token está vacío / incompleto (truncado)» | Copia de nuevo el token completo |
| «El token no fue emitido por ViewLBA o fue modificado» | No alteres el token; pide uno nuevo |
| «El token de licencia NO corresponde a este equipo» | Ese token es de otra instalación — pide uno nuevo |
| «La licencia está vencida» | Pide una renovación |
| «La licencia comienza el DD/MM/YYYY» | Actívalo a partir de esa fecha |
| «Ya existe una licencia con este identificador» | Usa el token más reciente |
| «La nueva licencia vence ANTES que la actual activa» | Pide una renovación igual o más larga |

En cualquier rechazo **no se modifica nada**: la licencia actual (si existe)
sigue vigente.
